Each `<name>.caption.txt` holds the figure's working caption and the method used to compute its numbers; the paper captions are in `report/REPORT.md`.

To regenerate a figure, run its script from `third_party/llm-agent-collusion` with `PYTHONUTF8=1 uv run python ../../scripts/figures/<name>.py`; scripts that need the raw runs take `--results-dir` and fall back to the committed CSV when the folder is absent.

The five body figures are drawn at their printed size (6.5 in wide: Letter with 1 in margins) and saved at 300 dpi, so a font size in points is the printed size; `scripts/figures/printcheck.py` refuses a body figure with text under 8 pt, text outside the figure or overlapping text, and prints each file's pixel size, print size and smallest font. Embed each at `{width=6.5in}`. The appendix figures D1, D2 and D4 to D7 are drawn the same way (D6 at 4.5 in wide); D3 (`fig_pretrend.png`, 200 dpi, 8 pt at 6.5 in) and D8 (M.S.'s, placed at 5.2 in) are kept as they were and must not be printed smaller. The scripts in `scripts/figures/ms/` are adapted copies of M.S.'s scripts (refs `origin/mert_sprint_sync_oct25` and `origin/mert_fig1_offer_gpt41`); each header names its source.
